# HITS WP1R-B Timing Audit

This package reports the aggregate timing/source audit for the frozen HITS primary cohort and the exact historical CBC row-selection rule. It contains no patient-level identifiers, row-level timestamps, individual classifications, or raw clinical data.

**Gate:** `WP1R_B_PASS_SELECTION_RULE_ONLY`.

**Scope:** timing/source verification and factual review handoff only. Model results and manuscript files were not changed.

Start with `00_EXECUTIVE/WP1R_B_EXECUTIVE_SUMMARY.md`, then review the gate, source inventory, measurement-selection rule, timing tables, study-period audit, temporal decision, and reviewer fact patterns. The executable audit and checksums are in `09_CODE/`.
